# web-client

Interfaz web del sistema. Solo se comunica con el API Gateway (RNF21).

- **Framework:** Laravel con plantillas Blade y Bootstrap · **Base de datos:** ninguna
- Debe poder usarse en pantallas desde 360 px de ancho (celular o tableta en la bodega).
- Envía el token de sesión en la cabecera `Authorization: Bearer <token>`.
